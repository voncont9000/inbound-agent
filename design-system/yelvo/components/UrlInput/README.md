# UrlInput

The hero capture field: a website address in, a generated assistant out. Provide `onSubmit(url)`, and optionally `placeholder`, `action` and `hints`.

- Sits under the hero `lead`. The shell uses `radius-lg`, the button inside is a `cta` `lg` button.
- On focus the border becomes `accent` with `shadow-glow`.
- `hints` render as check marked reassurances underneath ("Free personalised AI", "No signup"). Two, never more than three.

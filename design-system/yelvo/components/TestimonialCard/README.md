# TestimonialCard

A customer quote with attribution. Provide `quote`, `name`, `role`, and optionally `avatar` (an image URL). Without `avatar` it shows initials on `accent-soft`.

- Use real customer words, unedited apart from length. Quote marks are not added; the card shape signals the quote.
- Lay them out in a horizontally scrolling row or a 3 column grid with `space-8` gaps.

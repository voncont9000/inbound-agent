The General tab contains the assistant's basic identity and spoken style. Choose details that callers will recognise and test the result before using it.

## Update the assistant's details

1. Open the assistant's settings and select **General**.
2. Set the assistant name and business name.
3. Choose the language or languages the assistant should use and select a voice.
4. Review the greeting and instructions so they match your organisation.
5. Choose **Save changes**.

## Check how it sounds

1. Start a **Test call**.
2. Listen to the greeting and check pronunciation, language and tone.
3. Return to General settings to adjust anything that needs improvement.

### Good to know

Language availability depends on the options shown in the app. Do not assume that a voice or language is available if it is not listed.

A test call lets you try an assistant before using it with real callers. Test calls are marked **Test call**, are excluded from dashboard conversation counts, and do not run after-conversation actions.

## Start a test call

1. Open the assistant you want to check.
2. Choose **Test call**.
3. Follow the prompt to open the test call and speak naturally.
4. Try a typical question, provide example details and check how the assistant responds.

## Review the result

1. Check that the greeting, voice and language are suitable.
2. Check that the assistant uses the expected business information and rules.
3. Adjust settings and test again if anything needs correction.

### Good to know

Test calls are for practice. They do not send after-conversation notifications, customer emails, spreadsheet rows or webhooks.

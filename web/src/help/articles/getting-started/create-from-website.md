The website setup flow uses public website content to draft assistant details and knowledge. Review each draft before accepting it; imported text is a starting point, not a substitute for checking accuracy.

## Start the website setup

1. Open [Assistants](/assistants) and choose the option to create an assistant.
2. Select **Set up from website**.
3. Enter the website address and follow the setup prompts.

## Review the draft

1. Read each proposed section and check it against your organisation's current information.
2. Choose **Accept** to keep a section, **Edit** to change it, or **Discard** to leave it out.
3. When editing, choose **Save and accept** to keep your changes, or **Cancel edit** to return without saving.
4. Complete the setup and review the assistant in [settings](/assistants).

### Good to know

If the site returns no readable text, check that the address is correct and the information is available on the public pages being imported. You can add or correct details later in Knowledge settings.
